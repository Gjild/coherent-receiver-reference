# Intellectual Architecture — Working Hypothesis

**Status:** not yet developed/accepted.

The book should progress from motivated coherence problems and observables, through mathematical/physical foundations, to receiver systems, architectures, implementation, calibration, verification and production. Lifecycle order and teaching order need not coincide. Complete reference designs should be defined early as coverage tests, and developed progressively.

Do not finalize parts/chapters until the competence inventory, technical dependencies and representative reference-design problems have been assessed. A table of contents is an *output* of this work, not an imposed input.
